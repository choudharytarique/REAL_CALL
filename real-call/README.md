# Real Call — Spoken English Practice

- **1-on-1 Real Call** — live voice only between real people (WebRTC audio). No video.
- **AI Voice Call** — characters with Ollama when configured
- **12 Learning Games** — vocab, grammar, spelling, idioms, sentences
- **English Learning Resources** — original lessons
- **Policy pages** — About, Contact, Privacy, Terms, Cookies, Community, Safety, Disclaimer, Help/FAQ

## Quick start
```bash
cd real-call
npm install
node server.js
```
Open http://localhost:3000

## Google Login
Set GOOGLE_CLIENT_ID in index.html after creating an OAuth Web client ID. Never put secrets in frontend code.

## Config
PORT (default 3000), OLLAMA_URL, OLLAMA_MODEL

robots.txt and sitemap.xml are served from the project root.
